Datenschutzerklärung

Diese Datenschutzerklärung gilt für die Anwendung Trend-Tool von freefunandtech Austria.

Wer die Anwendung nutzt

Trend-Tool ist ein privates Programm. Es wird ausschließlich vom Betreiber selbst für seine eigenen YouTube-Kanäle genutzt. Es gibt keine fremden Nutzerinnen und Nutzer und keine Registrierung.

Welche Google-Daten verwendet werden

Nach der Anmeldung mit dem eigenen Google-Konto greift das Programm über die YouTube Data API auf den eigenen YouTube-Kanal zu: Kanalname, Kanalbeschreibung, Playlists und eigene Videos. Damit werden Playlists angelegt, Kanalbeschreibungen aktualisiert und eigene Videos hochgeladen.

Speicherung

  • Die Anmeldedaten (Zugangs-Token) werden nur lokal auf dem PC des Betreibers gespeichert.
  • Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung verwendet.
  • Es gibt keinen eigenen Server; diese Webseite setzt keine Cookies und enthält keine Analysewerkzeuge.

Einhaltung der Google-Richtlinien

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Es gelten außerdem die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Zugriff widerrufen

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Dabei werden die lokal gespeicherten Zugangsdaten unbrauchbar.
