Datenschutzerklärung

Diese Datenschutzerklärung gilt für die Anwendung Trend-Tool von freefunandtech Austria.

Wer die Anwendung nutzt

Trend-Tool ist ein privates Programm. Es wird ausschließlich vom Betreiber selbst für seine eigenen YouTube-Kanäle genutzt. Es gibt keine fremden Nutzerinnen und Nutzer und keine Registrierung.

Welche Google-Daten verwendet werden

Nach der Anmeldung mit dem eigenen Google-Konto greift das Programm über die YouTube Data API auf den eigenen YouTube-Kanal zu: Kanalname, Kanalbeschreibung, Playlists und eigene Videos. Damit werden Playlists angelegt, Kanalbeschreibungen aktualisiert und eigene Videos hochgeladen.

Speicherung

  • Die Anmeldedaten (Zugangs-Token) werden nur lokal auf dem PC des Betreibers gespeichert.
  • Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung verwendet.
  • Es gibt keinen eigenen Server; diese Webseite setzt keine Cookies und enthält keine Analysewerkzeuge.

Einhaltung der Google-Richtlinien

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Es gelten außerdem die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

YouTube API Services

Trend-Tool verwendet die YouTube API Services. Wer die Anwendung nutzt, stimmt den Nutzungsbedingungen von YouTube zu. Für die Verarbeitung durch Google gilt die Datenschutzerklärung von Google.

Zusätzlich liest das Programm öffentliche Angaben zu beliebten Videos (Titel, Kanal, Aufrufe, Likes) für eine eigene Trend-Statistik. Diese Daten werden nur lokal gespeichert. Videos, die nicht mehr unter den beliebten auftauchen, werden nach 30 Tagen samt Daten gelöscht; öffentliche Kennzahlen und daraus abgeleitete Werte (z. B. Summen je Thema) werden höchstens 36 Monate aufbewahrt.

Zugriff widerrufen und Daten löschen

Der Zugriff kann jederzeit in den Sicherheitseinstellungen des Google-Kontos unter security.google.com/settings/security/permissions widerrufen werden. Dabei werden die lokal gespeicherten Zugangsdaten unbrauchbar. Gespeicherte Daten können jederzeit gelöscht werden, indem die Anmeldung im Programm entfernt bzw. die lokale Datenbank gelöscht wird; auf Anfrage an die unten genannte Kontaktadresse werden alle Daten innerhalb von 7 Tagen gelöscht.

English – Privacy Policy (summary)

Trend-Tool is a private desktop application used only by its operator for his own YouTube channels. It uses the YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

  • Data accessed: after Google sign-in, the operator's own channel (channel name and description, playlists, own videos) to create playlists, update channel descriptions and upload own videos; public statistics of popular videos (title, channel, views, likes) for a private trend statistic.
  • Storage: locally on the operator's PC only. No server, no sharing with third parties, no selling, no advertising, no cookies or analytics on this website. Public API data is refreshed regularly and deleted 30 days after a video stops appearing among popular videos; public statistics and derived metrics are kept for at most 36 months.
  • Revoking access / deletion: access can be revoked at any time via Google security settings; stored data can be deleted at any time, and on request to the contact address above all data is deleted within 7 days.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
